The baseline pins every agent's KV Cache in GPU memory. PhaseWeaver releases it when the agent enters a tool phase and gives the capacity to someone else. Move the sliders to see the trade: goodput and tail latency against recompute cost. Every number below is a real simulator run, not a chart drawn by hand.

Prefix caching: the honest null result [L2]

prefix_hit_ratio is an assumed upper bound on how much recompute prefill a shared prefix cache could remove. It does not implement refcounting or block dedup. Eliminating recompute entirely barely moves goodput on these workloads — the binding constraint is tool time and duty cycle, not prefill. Capacity amplification (more agents in the same memory) is not modelled here.
